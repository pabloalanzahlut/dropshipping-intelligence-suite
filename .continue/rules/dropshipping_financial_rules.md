# REGLAS FINANCIERAS DE VALIDACIÓN (ADRIÁN SÁENZ & IVÁN CAICEDO)

Cada vez que el usuario te pida analizar un producto, calcular un margen o estructurar datos en SQLite, debes aplicar y validar estas directrices:

1. **Multiplicador mínimo 2x:** el PVP debe ser al menos 2 veces el **coste landed** (producto + envío). Si no llega, rechaza el producto (Adrián Sáenz, Q4Ykcwh5Osc 24:40).
2. **Multiplicador objetivo 3x:** si el PVP no llega a 3 veces el coste landed, advierte y sugiere subirlo si el producto lo permite.
3. **Coste de origen $5–15** (recomendado) y **ROAS mínimo 2** medido real, no el que declara Meta.
4. **Costes reales del P&L:** fees Shopify + divisa 4,0 % y cancelaciones/devoluciones 10,1 % de la facturación.
5. **Baterías de litio sueltas:** categoría prohibida (restricción aduanera).

El curso NO fija umbral de margen (%) ni límite de peso (kg): no los apliques ni los inventes.
