# REGLAS DE E-COMMERCE CRO & COPYWRITING (AIDA FRAMEWORK)

Cada vez que uses el comando `/copywrite` o redactes descripciones para la landing page, debes ajustarte a esta estructura:

1. **Atención (0-3s):** Gancho visual directo enfocado en el dolor. Prohibido usar introducciones corporativas o saludos vacíos.
2. **Interés:** Resalta el "Factor Wow" del producto utilizando viñetas limpias y negritas en los beneficios emocionales.
3. **Fidelidad de Datos:** Queda estrictamente prohibido alterar dimensiones, materiales o capacidades del fabricante para "embellecer" la oferta. Modificar datos duros causa bloqueos en pasarelas de pago.
4. **Cero Humo:** No uses adjetivos superlativos vacíos como "el mejor artículo del universo". Fundamenta el deseo en la demostración práctica de la solución.
