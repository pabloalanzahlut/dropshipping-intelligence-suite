## ⚡ DIFERENCIA CLAVE: ORGÁNICO vs PAID ADS

| Criterio | Paid Ads (Meta/TikTok) | Orgánico (TikTok/Reels/FB) |
|----------|----------------------|---------------------------|
| Velocidad de validación | 3-7 días | 7-21 días |
| Coste de entrada | €30-100/día | €0 |
| Escala posible | Alta (con presupuesto) | Limitada (a menos que viralice) |

## ✅ CRITERIOS ESPECÍFICOS PARA ORGÁNICO

### 1. Factor WOW (obligatorio)
El video debe provocar una reacción en los primeros 3 segundos:
- "No sabía que esto existía"
- "¿Dónde lo compro?"
- "Se lo mando a alguien"

**Test rápido:** Muéstrale el video (sin caption ni audio) a alguien que no conoce el producto. Si pregunta "¿qué es eso?" → tiene factor WOW. Si no reacciona → descártalo para orgánico.

### 2. Demostración visual obvia
- [ ] El problema y la solución se ven en < 5 segundos
- [ ] No requiere texto para entender qué hace
- [ ] Transformación visible (antes → después en el mismo clip)

**Categorías con alto factor WOW para orgánico:**
```
✅ Organizadores y almacenamiento (transformación visual inmediata)
✅ Gadgets de cocina (demostración en acción)
✅ Productos de limpieza (resultado antes/después obvio)
✅ Accesorios para mascotas (emoción + usabilidad)
✅ Gadgets de luz / LED (efecto visual impactante)
✅ Productos para el sueño / relajación (aspiracionales)
```

**Categorías con bajo rendimiento en orgánico:**
```
❌ Suplementos (no hay demostración visual clara)
❌ Ropa genérica (sin diferenciador visual)
❌ Productos financieros / servicios
❌ Productos con instrucciones complejas
```

### 3. Precio asequible (impulso de compra)
- Rango de precio: **por definir con datos reales**. El curso fija coste de origen $5–15 y PVP ≥ 2× coste landed (objetivo 3×)
- Por encima de €50: necesita más confianza → mejor para paid ads + retargeting
- Por debajo de €10: margen insuficiente (regla 2x/3x GEM OS sobre coste landed)

### 4. Shareable (compartible)
- [ ] El video genera reacción de "se lo envío a alguien"
- [ ] Resuelve un problema común (no de nicho ultra-específico)
- [ ] Tiene elemento de entretenimiento o sorpresa

### 5. Masa crítica de búsqueda (validación previa)
Antes de crear contenido, verificar:
```
TikTok: buscar el producto → ¿hay videos con > 100K views?
        Si hay → el mercado existe. Si no → alto riesgo.

Google Trends: tendencia estable o creciente (no pico puntual)

AutoDS Trending: clasificación HOT o WARM (skill /clasificar-producto)
```
