## 📸 FOTO DE PERFIL

### Reglas visuales
| Criterio | Recomendación |
|----------|---------------|
| Fondo | Blanco o de un solo color sólido (máx. 1 color) |
| Elemento principal | Logo de la tienda o imagen del producto estrella sin fondo |
| Formato | Círculo de 200×200 px mínimo (subir 400×400 para evitar pixelado) |
| Texto | Ninguno — es ilegible a tamaño miniatura |
| Estilo | Limpio, profesional, reconocible a 30px de tamaño |

### Para tienda sin producto definido (fase actual)
Usar **logo de la marca** con fondo blanco. Si no hay logo, usar un icono de la categoría del nicho en color de marca.

**Herramienta gratuita:** Canva → Plantillas de logo → Exportar PNG fondo transparente → poner sobre fondo blanco sólido.

## 🔗 ENLACE BIO (Link in Bio)

**Estrategia recomendada por el curso:** Un solo link que lleva a la tienda Shopify.

### Opción A — Directo a tienda (más simple)
```
Enlace: https://tu-tienda.myshopify.com
```

### Opción B — Linktree (más conversión)
Usar cuando tengas más de 1 producto o quieras trackear clicks.
```
Linktree: https://linktr.ee/nombretienda
  → 🛒 Ver productos  → tu-tienda.myshopify.com
  → 💬 WhatsApp       → wa.me/+34XXXXXXXXX
  → ⭐ Reseñas         → página de reseñas
```

**Para fase actual (sin producto definido):** usar Linktree con un solo botón "Lista de espera" → formulario de captura (fake-door, ver skill `/fake-door`).

## ✍️ DESCRIPCIÓN / BIO (150 caracteres máx.)

### Fórmula: Qué haces + Para quién + CTA
```
[Nicho/Producto] para [audiencia] ✅
🚚 {{ENVIO_REAL}} | 🔄 {{GARANTIA_REAL}}
👇 Ver productos
```

### Ejemplos por nicho
```
Gadgets para organizar tu hogar 🏠
🚚 {{ENVIO_REAL}} | 🔄 {{GARANTIA_REAL}}
👇 Tienda en el link
```
```
Productos para dormir mejor 😴
Sin pastillas. Sin trucos. Solo diseño.
👇 Ver tienda →
```

### Reglas de bio
- [ ] Emoji al inicio de cada línea (aumenta legibilidad en móvil)
- [ ] Mencionar envío o garantía solo si son reales y constan en la política de la tienda
- [ ] CTA en la última línea siempre
- [ ] Sin hashtags en la bio de TikTok (no funcionan ahí)
